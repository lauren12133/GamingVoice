削波风险

辐条长度 = 该方向增益；圆点大小与亮度 = 该方向实时电平（越响越大越亮）。

按声道区分敌我：多数游戏把自己的枪声混在中置(FC)，靠「自身枪声 / 自身脚步」从左右声道减掉；COD 等把自己枪声放在 FL/FR 的中央分量，主要靠「敌我诊断」里的 Duck 深度压。四个旋钮越往右，自声减得越多、敌人脚步抬得越高、听得越远；8 个方向推子保持中性即可。若「中置」格开枪时不跳，说明游戏只输出了立体声（FC 是空的）。
